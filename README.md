# Rajasvi Group - Official Website

A modern, responsive, and high-performance corporate web portal for **Rajasvi Group**, showcasing expertise across Engineering, Construction, Marine Services, and Heavy Industrial Fabrication.

## 🚀 Features

- **Modern Visual Architecture**: Built with Tailwind CSS and styled with custom typography (Outfit & Inter fonts).
- **Responsive Layout**: Seamless experience across mobile, tablet, and desktop viewports.
- **Interactive Navigation & UI Components**: Smooth scrolling, dynamic section switches, and polished UI micro-animations.
- **Service & Portfolio Showcases**: Comprehensive overview of Rajasvi Group's engineering, marine, construction, and fabrication capabilities.
- **Contact & Inquiry System**: Integrated direct communication channels and call-to-action touchpoints.

## 🛠️ Tech Stack

- **HTML5**: Semantic markup structure.
- **Tailwind CSS**: Utility-first CSS framework for modern styling.
- **Font Awesome**: High-quality vector icons.
- **JavaScript (ES6+)**: Interactive components and navigation logic.

## 💻 Getting Started

Simply open `index.html` in any web browser to view the application locally, or host it via GitHub Pages.
